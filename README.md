# dotfiles

Personal Omarchy configuration — Hyprland keybinds, terminal fonts, bar widgets,
and the niri-style scrolling workspaces.

## Layout

```
config/hypr/          bindings, input, look-and-feel, monitors (Lua)
config/alacritty|foot|kitty|ghostty/   terminal font sizes
config/omarchy/       bar layout (shell.json), font size, default agent
bin/                  helper scripts on PATH
state/                workspace layout rules (scrolling on workspaces 1, 2, 5)
scripts/              helpers called by install.sh
plugins.txt           third-party bar widgets + their git URLs
theme.txt             theme display name
```

## New machine

```sh
git clone <this-repo> ~/dotfiles
cd ~/dotfiles && ./install.sh
```

`install.sh` copies every file into place (backing up anything it overwrites),
sets the theme, installs and enables the plugins, then reloads Hyprland and
fails if `hyprctl configerrors` reports anything.

Preview first with `./install.sh --dry-run`.

## Day to day

Configs are edited in `~/.config` as usual — Omarchy's own tools write there.
When the machine has changes worth keeping:

```sh
./install.sh --save     # copy machine -> repo
git add -A && git commit
```

Going the other way (after `git pull`, or to reset drift):

```sh
./install.sh            # copy repo -> machine
```

`--save` only touches files already tracked by the repo, so it never pulls in
unrelated files from `~/.config`.

## Notes

- **Copies, not symlinks.** `omarchy refresh` writes through symlinks and would
  clobber the repo, so these are real files. Re-run `./install.sh` after an
  Omarchy refresh if you want your versions back.
- **`state/`** holds `workspace-layouts/{1,2,5}.lua`, which make those
  workspaces use the scrolling (niri-style) layout. They are regenerated by
  `SUPER + ALT + L` (`omarchy-hyprland-workspace-layout-toggle`), so a saved
  copy here is just the starting point for a new machine.
- **`scripts/`** must stay alongside `install.sh`; it resolves paths relative to
  its own location.
- Files Omarchy ships unmodified (branding, menu extensions, sample hooks,
  btop/tmux/git/starship) are deliberately not tracked.
